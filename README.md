## Descripción

Atari Pong es un videojuego desarrollado en Python utilizando
la biblioteca Pygame. El sistema recrea la dinámica básica del
videojuego Pong, permitiendo que dos jugadores controlen las
paletas y compitan para obtener puntos.

## Objetivo del sistema

Desarrollar un videojuego funcional aplicando los conocimientos
de programación, estructuras lógicas, estructuras repetitivas,
organización del código y arquitectura de software adquiridos
durante la asignatura.

## Funcionalidades

- Menú principal.
- Inicio de partidas.
- Control de las paletas.
- Movimiento de la pelota.
- Detección de colisiones.
- Sistema de puntuación.
- Determinación del ganador.
- Registro de resultados.
- Consulta de marcadores de partidas anteriores.
- Salida del programa.
